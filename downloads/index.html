Install neuro-sync.

Run one command for your system. It downloads a single verified binary and hands back your shell: no admin access, no browser, no dependencies. When a DICOM export folder is ready, point neuro-sync at it.

One folder, every supported MR Image series: functional, structural, diffusion, perfusion, field maps, references, localizers, and derived MR are metadata-deidentified and synced. Native pixels are not defaced and may contain recognizable anatomy, so institutional authorization is required. Unsafe or unsupported DICOM objects remain local.

What happens next

  1. The installer finishes and hands back your terminal. Nothing launches automatically.
  2. When a DICOM export folder is ready, run neuro-sync with its path.
  3. The first run walks a one-minute registration in the terminal: a private, revocable upload identity for that workstation, plus a confirmation that the folder is approved for contribution.
  4. Each run archives every supported MR Image series, removes identifying metadata on the workstation, and uploads with live progress and automatic continuation.

The original files remain unchanged. Rewritten DICOM copies retain scanner-native Pixel Data and useful standard acquisition metadata; identifying fields, dates, raw UIDs, free text, and unsafe private data are removed or remapped before upload. Pixel Data is not defaced, cropped, masked, or resampled, so structural/head images may retain recognizable facial anatomy. The cluster independently verifies every archive; only confirmed functional EPI is converted to native-space NIfTI.

Current boundary: this is durable archiving plus EPI conversion and validation—not a full preprocessing or repository-submission pipeline. It does not yet perform motion correction, distortion correction, registration, normalization, BIDS curation, or structural defacing. Read the exact intake contract.
