What happens next

  1. The installer finishes and returns control to your terminal. It does not launch neuro-sync automatically.
  2. Find or copy the completed DICOM export-folder path, then run the command printed by the installer.
  3. Complete the one-minute terminal registration and authorization confirmation. Nothing opens in a browser.
  4. Run neuro-sync /path/to/dicom-export. neuro-sync selects compatible functional EPI, removes identifying DICOM fields, and uploads with a live progress bar, speed, ETA, and automatic continuation.

The original files remain unchanged. Privacy-cleared functional DICOM copies retain scanner-native pixel data and useful standard acquisition metadata; identifying fields, dates, raw UIDs, free text, and unsafe private data are removed or remapped before upload. Scanner make/model/software is provenance, not a whitelist. Structural, diffusion, reference, derived, ambiguous, and privacy-unsafe scans stay local. Conversion and scientific validation run asynchronously on Scaling Neuro's research cluster after the upload receipt is complete. See the measured conversion matrix.
