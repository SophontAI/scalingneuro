How it works

The scanner export is enough.

There is no conversion pipeline and no prescribed preprocessing stack.

01

Find

neuro-sync walks one folder recursively and identifies functional EPI time series from DICOM metadata.

02

Protect

Direct identifiers, dates, free text, file paths, and unsafe private metadata are removed locally. Pixel Data is preserved.

03

Sync

Each deidentified EPI series is archived and uploaded to R2 with resumable transfers and content hashes.

04

Use

Participating labs download the DICOM archives and preprocess them with the tools and compute they already use.

Structural scans, localizers, diffusion, field maps, secondary captures, and ambiguous series stay on the workstation. Scaling Neuro does not deface images, convert DICOMs to NIfTI, or run preprocessing.

Share data

One command after installation.

Register the workstation once, then point neuro-sync at any institutionally authorized DICOM export folder. Rerun the same command after an interruption and completed work is reused. 

# macOS or Linux
$ curl -fsSL https://scalingneuro.com/install.sh | sh
$ neuro-sync /path/to/dicom-folder

Reading DICOM headers          complete
Functional EPI series          4
Other series left local        11
Deidentified DICOM archives    uploaded

✓ 4 EPI series safely stored

Access data

Join the open data effort.

Archive access is available to researchers whose lab agrees to participate in this shared functional MRI effort. Submit the form once to receive a personal access token for the archive.

  • Deidentified functional EPI DICOM archives
  • Acquisition metadata retained for independent preprocessing
  • No required cloud compute, conversion, or analysis service

Your work email is used only to administer archive access and coordinate this effort.

Access granted

Save this token now.

It is shown once. Treat it like a password.

Save it in your shell, then list the archive:

export SCALING_NEURO_ACCESS_TOKEN='PASTE_TOKEN'
curl -H "Authorization: Bearer $SCALING_NEURO_ACCESS_TOKEN" \
  https://scalingneuro.com/v1/archive

Use any listed download_url to download a series:

curl -L -H "Authorization: Bearer $SCALING_NEURO_ACCESS_TOKEN" \
  DOWNLOAD_URL -o series.dicom.tar.zst
shasum -a 256 series.dicom.tar.zst
