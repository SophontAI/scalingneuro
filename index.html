        03 — For every new session
        
Point it at one folder. Make eligible scans count.

        

          Keep the scanner workflow. Install once, return to the shell, and run neuro-sync whenever the export path is ready. It conservatively selects compatible functional EPI, removes identifying DICOM fields locally, and uploads each series with resumable checksums. The workstation is finished when transfer receives its durable receipt; conversion and scientific validation continue on the research cluster.
        

        
The current measured beta accepts only classic Siemens Prisma_fit/E11 mosaic and Philips Achieva dStream/5.1.1 exports that satisfy the complete privacy and metadata contract. Other scanners, Enhanced MR, GE, structural, diffusion, reference, derived, and uncertain series stay local with a report code.


        

          One terminal commandNo admin, Python, or DockerFails closed
        


        

          

            
            
            
          

          

            
# macOS or Linux — installs, verifies, then returns to your shell
$ curl -fsSL https://scalingneuro.com/install.sh | sh

# later, after you find or copy the DICOM folder path
$ neuro-sync /path/to/new_session_dicoms

✓ Private, revocable identity for this workstation
✓ Confirm the selected folder is approved for contribution

✓ Interrupted? Rerun this same folder command; completed work is reused
